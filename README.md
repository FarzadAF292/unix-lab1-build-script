# unix-lab1-build-script

# Лабораторная работа 1 — Скрипт для сборки

# Афзалли Фарзад — 932404

В данном проекте реализован POSIX-совместимый shell-скрипт для сборки программы на языке C++.

## Файлы

- `build.sh` — скрипт сборки
- `main.cpp` — пример исходного файла на C++

## Формат исходного файла

Исходный файл должен содержать комментарий с именем конечного файла:

```cpp
// Output: hello
```

Скрипт распознаёт `Output:` только в комментарии вида `// Output: ...`.

Например, строка:

```cpp
cout << "Output: fake";
```

не будет воспринята как имя конечного файла.

## Запуск

Пример запуска:

```sh
sh build.sh main.cpp
```

## Принцип работы

Скрипт выполняет следующие действия:

1. Проверяет количество переданных аргументов.
2. Проверяет существование исходного файла.
3. Определяет абсолютный путь к исходному файлу.
4. Сохраняет каталог, из которого был запущен скрипт.
5. Находит комментарий `// Output: ...` и извлекает имя конечного файла.
6. Проверяет корректность имени конечного файла.
7. Создаёт временный каталог с помощью `mktemp`.
8. Переходит во временный каталог с помощью `cd`.
9. Выполняет компиляцию программы внутри временного каталога.
10. После успешной сборки перемещает конечный файл обратно в каталог запуска скрипта.
11. Удаляет временный каталог при обычном завершении работы и при обработке сигналов.

## Временный каталог

Временный каталог создаётся с помощью:

```sh
TMPDIR=$(mktemp -d)
```

После этого скрипт переходит в него:

```sh
cd "$TMPDIR"
```

Таким образом, сборка выполняется непосредственно во временном каталоге, и промежуточные файлы остаются внутри него.

## Конечный файл

После успешной компиляции готовый файл перемещается в каталог, из которого был запущен скрипт:

```sh
mv "$OUTPUT" "$START_DIR/$OUTPUT"
```

Например, если скрипт был запущен из каталога проекта, а исходный файл находится в другом каталоге, конечный файл всё равно будет создан в каталоге запуска скрипта.

## Обработка сигналов

Для очистки временного каталога используется `trap`.

Обрабатываются сигналы:

- `HUP`
- `INT`
- `QUIT`
- `TERM`

При получении одного из этих сигналов вызывается функция завершения, которая удаляет временный каталог и завершает работу скрипта с соответствующим кодом.

Кроме того, временный каталог удаляется и при обычном завершении скрипта.

## Коды ошибок

Скрипт использует следующие коды завершения:

- `1` — передано неверное количество аргументов
- `2` — исходный файл не найден
- `3` — комментарий `Output:` не найден
- `4` — не удалось создать временный каталог
- `5` — ошибка компиляции
- `6` — не удалось переместить конечный файл
- `7` — некорректное имя конечного файла
- `8` — не удалось перейти во временный каталог

## Пример исходного файла

```cpp
// Output: hello

#include <iostream>

using namespace std;

int main()
{
    cout << "Hello, UNIX!" << endl;
    return 0;
}
```
