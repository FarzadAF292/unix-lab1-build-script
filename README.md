# unix-lab1-build-script

# Лабораторная работа 1 — Скрипт для сборки

# Афзалли Фарзад - 932404

В данном проекте реализован POSIX-совместимый shell-скрипт для сборки программы на C++.

## Файлы

- `build.sh` — скрипт сборки
- `main.cpp` — пример исходного файла на C++

## Формат исходного файла

Исходный файл должен содержать комментарий с именем конечного файла:

```cpp
// Output: hello
```
